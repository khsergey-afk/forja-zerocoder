# forja-deck — доклад в стиле Forja

Собирает доклад из описания в JSON и проверяет вёрстку. Стиль — `forja`, из библиотеки stylekit AgentKit.

## Что нужно

- AgentKit с stylekit: `src/agentkit/skills/pptx/scripts/pp.py`
- Файл стиля `style/forja.json` из этого репозитория — положить в `src/agentkit/stylekit/data/стили/`
- Шрифт **Onest** в системе (без него PowerPoint подставит Segoe UI: палитра и геометрия останутся, типографика изменится)

## Как собрать

```bash
python <agentkit>/src/agentkit/skills/pptx/scripts/pp.py build описание.json \
  --out доклад.pptx --style forja --png tmp/png
python <agentkit>/src/agentkit/skills/pptx/scripts/pp.py check доклад.pptx
python <agentkit>/src/agentkit/skills/pptx/scripts/pp.py md доклад.pptx --out доклад.md
```

Коды выхода: `0` — готово, `1` — ошибка описания или вёрстки (см. `errors`), `2` — нет PowerPoint.

## Описание доклада

```json
{
  "title": "Название",
  "date": "01.11.2026",
  "style": "forja",
  "author": "Имя",
  "position": "Должность или организация",
  "slides": [
    {"layout": "cover", "kicker": "Рубрика", "title": "Заголовок", "subtitle": "Подзаголовок", "date": "01.11.2026"},
    {"layout": "cards", "kicker": "Проблема", "title": "Тема", "sub": "Главная мысль",
     "cards": [{"head": "Тезис", "text": "Одна-две фразы"}],
     "callout": {"head": "Вывод", "text": "С **акцентом** жирным"},
     "source": "Откуда цифры", "notes": "Что сказать вслух"}
  ]
}
```

Раскладки: `cover`, `section`, `kpi`, `chart`, `table`, `cards`, `steps`, `text`, `thanks`.

## Правила стиля Forja

- **Один слайд — одна мысль.** Заголовок — тема, до 60 знаков. Главная мысль — в `sub`, крупно.
- **Карточек не больше шести**, тезисов не больше пяти, слов на слайде — до 60. Слайд читают глазами один раз.
- **Числа — только со сноской.** Либо из книги расчётов (`num` и `{id}` по манифесту), либо через `source` у слайда. Числа «из головы» не ставим.
- **Акцент — один на слайд.** Если всё выделено, не выделено ничего.
- **Подложка `callout`** — огненная (тёплая), это единственное место, где допустим цветной блок.

## Палитра (не менять без причины)

| Роль | Цвет | Где |
|---|---|---|
| Фон | `#F6F4EF` | база всех слайдов |
| Карточка | `#EFEBE3` | плашки тезисов |
| Текст | `#1C1A16` | заголовки и тело |
| Вторичный текст | `#5C564C` | подзаголовки, сноски |
| Акцент | `#2E3BD6` | номера, выделение, диаграммы |
| Огонь | `#FBE6D6` / `#9A4A12` | подложка вывода |
| Хорошо / Плохо | `#2B7A47` / `#C2362B` | только по смыслу |

Шрифт один — **Onest**. Числа — он же, с табличными цифрами.

## Проверка перед выдачей

1. `check` без ошибок (`errors: []`).
2. Посмотреть PNG каждого слайда: текст не наезжает, ничего не вылезает.
3. Сверить сноски: у каждого показателя и таблицы есть `Источник:` или `Расчёт:`.

## Чего не делать

- Не рисовать фигуры поверх макета вручную — раскладки и библиотека объектов stylekit закрывают почти всё.
- Не писать PDF-дубли доклада.
- Не публиковать в репозиторий данные заказчиков: только обезличенные примеры.
